# Lagon

Une barre élégante en haut de l’écran Windows : musique et paroles synchronisées, volume de chaque
appli, infos PC, temps d’écran, stats Twitch et rang Valorant. Gratuit et léger.

**Site et téléchargement : https://linor240.github.io/lagon/**

Les installateurs de chaque version sont dans les [Releases](https://github.com/linor240/lagon/releases).
Ce dépôt contient le site de présentation ; `demo/` est une copie de l’interface de Lagon qui tourne
avec des données inventées.

Lagon n’est affilié ni à Riot Games, ni à Twitch, ni à Spotify.
